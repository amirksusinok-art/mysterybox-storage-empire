# MysteryBox — Storage Empire

Одиночная браузерная игра на React, TypeScript и Vite. Все деньги виртуальные. Соперники и покупатели управляются правилами игры.

## Локальный запуск

Требуется Node.js 24 и npm.

```bash
npm ci
npm run dev
```

Откройте http://127.0.0.1:5173. Для проверки production-сборки выполните `npm run build`, затем `npm run preview`.

## Как играть

1. Осмотрите склад, запустите торги и повышайте ставку с учётом доставки.
2. Откройте выигранный склад. Заберите находки в гараж или сразу продайте их.
3. Проведите диагностику в мастерской. Почините вещь или разберите её на детали.
4. Продайте вещь на маркетплейсе. Учитывайте состояние, рыночный спрос и комиссию.

Прогресс хранится в IndexedDB для текущего адреса игры. Игровое время останавливается, пока вкладка скрыта или закрыта. Новые лоты появляются каждые пять минут игрового времени.

## Render

Сборка — `npm ci && npm run build`. Запуск — `npm start`. Node обслуживает собранные файлы из `dist` на порту Render.
